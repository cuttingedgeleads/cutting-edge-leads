# Approved Studio → Leads Import contract (v1)

User approved implementation: Cannot Service → archive normally + send private information → Leads Home Screen notification (user taps) → Import tab with waiting count and identifiable tiles → selected tile prefills a new request → successful save removes waiting status. Merely opening must not consume an import. No automatic listing, contractor notification, pricing decision, charge or customer creation. Actual iPhone notification activation remains a physical-device acceptance gate; no Safari navigation substituted.

## Stable wire contract — BOTH workspaces must implement exactly this
POST /api/integrations/studio/imports on fixed destination origin https://www.cuttingedgeleads.net.
Studio env: LEADS_IMPORT_URL (complete endpoint), LEADS_IMPORT_SECRET, LEADS_IMPORT_ENVIRONMENT (production in production; qa in QA).
Leads env: STUDIO_IMPORT_SECRET, STUDIO_IMPORT_ENVIRONMENT, STUDIO_IMPORT_RECIPIENT_EMAIL (one existing ADMIN; never taken from incoming JSON).
No keys/default secrets in source. Disabled/unconfigured integration fails closed. Only isolated tests may inject a loopback transport without production URL validation.
HMAC headers: X-Studio-Timestamp = integer Unix seconds; X-Studio-Signature = lowercase hex SHA256 HMAC(secret, timestamp + '.' + EXACT raw UTF-8 JSON bytes). Leading UTF-8 BOM and invalid UTF-8 are rejected before durable intake; accepted originals and hashes retain exact bytes (no reserialization). Accept at most +/-300 seconds; compare constant-time, require >=32-byte secret, reject oversized body before JSON parsing, max 262144 bytes. No redirects on sender. HTTPS/TLS verified in production.
JSON strict field allowlist (ALL keys present, unspecified information empty strings):
- version: 1
- source: 'command-studio'
- environment: exact configured environment
- transferId: UUID string (durable outbox id)
- sourceRecordId: 1..128 [A-Za-z0-9_-]
- sourceRevision: string max128 (archived revision)
- sourceActor: string max200 (authoritative actor, never trusted client impersonation)
- customerName max200, customerPhone max100, customerEmail max320
- address max4000 (original operational address), formattedAddress max4000 (authoritative full address), city max200, state max100, postalCode max32
- inquiryNotes max60000, estimatorNotes max60000, salesNotes max60000: PRIVATE imported context, never automatically mapped to published description
- sourcePhotoCount: integer >=0, <=10000 (photos remain preserved in Studio; no public photo replication)
All unspecified values stay blank; source estimate price is NOT lead-sale price. Do not geocode/pay to guess additional fields. Preserve complete original address even if structured city/state/ZIP unavailable.
Identity: durable uniqueness (source, environment, sourceRecordId) AND transferId. Store immutable original payload and SHA256 of raw bytes. Same identity/hash replay returns same id even after saving/publishing; conflicting content/identity =>409; never overwrites reviewed data. Sender persists exact serialized body once, signs with fresh timestamp per attempt.
201 new / 200 replay receipt JSON: {version:1, importId:<opaque-id>, transferId:<echo>, sourceRecordId:<echo>, payloadSha256:<hex of exact body>, status:'waiting'|'saved'|'published', notificationStatus:'sent'|'pending'|'unavailable'}.
Strictly verify receipt including source, transfer, hash, id syntax/nonblank, valid status and HTTP class before marking delivered. Do not trust/open a destination URL from response. No PII in notification/URLs/logs.

## Leads workflow
Private recipient-scoped durable Import model, excluded from Lead marketplace. ADMIN + current session required at EVERY count/list/detail/save/publish boundary; scope to configured recipient persisted on receipt, no client-supplied owner. Return uniform 404 for inaccessible IDs. Private/no-store/nosniff on new paths, network-only/no caching of private imports. Strict same-origin mutating browser requests; integration authenticates by HMAC, not cookies. Signed-out deep links return to exact validated import after login, never external redirect.
New Import tab in Admin navigation, badge counts WAITING records server-side (not unread; do not decrement solely in client). Paginated or bounded tile list with exact total count, name, full address, contact, private job context. Loading/error/retry distinct from zero. Refresh when focused/resumed, push received, save completed; protect late response/logout/account switch races, don't poll hidden screens. Empty fields neutral. Click tile loads prefilled request; no mutation on GET/view.
Save request is explicit, creates/persists an UNPUBLISHED editable request (can be in same import record's separate reviewedData), atomically moves WAITING→SAVED once, retains immutable source context, decrements authoritative waiting count. Saved requests remain reachable in a Saved requests section in Import (no extra top-level tab required). Use optimistic version/expectedUpdatedAt and idempotent exact retry; failed save leaves waiting. Do not mark consumed when just opening.
Allow deliberate subsequent Review & publish via existing LeadForm with prefilled saved fields; clear Publish lead wording and disclosure of normal contractor notifications. Missing marketplace fields (job type, sale price, etc.) require human input. Internal source context remains visibly PRIVATE, not copied to contractor description. Atomic once-only lead creation + import link/status, transaction guard + uniqueness; replay returns original lead and does not renotify. Existing Create Lead behavior stays unchanged. New request save never creates a live Lead or invokes email/SMS/contractor push.
Import notification sends only to the persisted recipient with current ADMIN authorization and enabled push, after durable receipt. Generic privacy-safe content + stable tag, URL only /admin/imports/<opaque-id>. Durable attempted/sent/pending state with claim/lease prevents concurrent replay spam; unavailable permission/subscription must not lose intake. Reuse existing VAPID identity, no rotation. Notification click validates same-origin URL; reuses/navigates suitable existing window or opens exact in-scope path. Preserve login continuation and manifest/install identity. Import badge separate from existing unread notification badge.
